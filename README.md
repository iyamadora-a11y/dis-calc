# 할인 계산기 (Discount Calculator)

금액과 할인율을 입력하면 할인금액과 최종 결제금액을 즉시 계산하는 반응형 웹앱입니다.
PC와 스마트폰 모두 동일한 기능을 사용할 수 있으며, 스마트폰에서는 홈 화면에 추가해 앱처럼 실행할 수 있습니다.

빌드 과정이 없는 순수 정적 사이트(Vanilla HTML/CSS/JS)입니다.

## Netlify 배포

### 방법 1 — 드래그 앤 드롭 (가장 간단)

1. <https://app.netlify.com/drop> 접속
2. `discount-calc` **폴더**를 페이지에 그대로 끌어다 놓기
   (ZIP을 받았다면 먼저 압축을 풀고, `index.html`이 들어 있는 폴더를 올립니다)
3. 몇 초 뒤 `https://<랜덤이름>.netlify.app` 주소가 생성됩니다
4. **Site configuration → Change site name** 에서 주소를 원하는 이름으로 변경

### 방법 2 — Git 연동 (지속 배포)

1. 이 폴더를 GitHub 저장소에 push
2. Netlify → **Add new site → Import an existing project** → 저장소 선택
3. 빌드 설정:

   | 항목 | 값 |
   |---|---|
   | Build command | *(비워 둠)* |
   | Publish directory | `.` |

4. **Deploy site** 클릭. 이후 push할 때마다 자동 재배포됩니다.

### 방법 3 — Netlify CLI

```bash
npm install -g netlify-cli
cd discount-calc
netlify deploy --dir=. --prod
```

## 주요 기능

| 구분 | 내용 |
|---|---|
| 실시간 계산 | 계산 버튼 없이 입력 즉시 결과 갱신 |
| 금액 입력 | 천 단위 콤마 자동 표시, 커서 위치 유지, 내부 계산은 숫자값으로 처리 |
| 빠른 할인율 | 5 / 10 / 15 / 20 / 25 / 30 / 40 / 50 % 버튼 |
| 결과 표시 | 원래 금액 · 할인율 · 할인금액 · 최종 결제금액, 할인 전후 흐름도 |
| 원금 역산 | 최종 결제금액과 할인율로 할인 전 원래 금액 계산 (별도 탭) |
| 연속 할인 | 1차 할인 후 추가 할인 적용, 단일 할인과의 차액·실질 할인율 비교 |
| 오류 처리 | 미입력 · 음수 · 문자 · 100% 초과 입력 차단, NaN 미노출 |
| 부가 기능 | 초기화, 결과 복사 (클립보드 실패 시 대체 방식) |
| 디자인 | 반응형(PC 중앙 정렬 / 모바일 전체 폭), 다크 모드 자동 대응 |

### 계산식

```
할인금액   = 원래 금액 × 할인율 ÷ 100
최종 금액  = 원래 금액 − 할인금액

연속 할인  = (원래 금액 − 1차 할인금액) 에 2차 할인율 적용
원금 역산  = 최종 금액 ÷ (1 − 할인율 ÷ 100)
```

- 할인율은 **퍼센트 값**으로 입력합니다 (`20` = 20%). 소수점 입력(`12.5`)도 가능합니다.
- 일반 할인 계산에서 할인율은 0~100% 범위로 제한됩니다.
- 금액은 원 단위로 반올림됩니다.
- 역산에서 할인율 100%는 원금을 계산할 수 없어 안내 메시지가 표시됩니다.

### 검증된 계산 예시

| 입력 | 결과 |
|---|---|
| 100,000원 / 20% | 할인 20,000원 → 80,000원 |
| 500,000원 / 25% | 할인 125,000원 → 375,000원 |
| 100,000원 / 20% + 추가 10% | 80,000원 → **72,000원** (단일 30% 할인 70,000원과 2,000원 차이, 실질 28%) |
| 역산: 80,000원 / 20% | 원래 금액 100,000원 |

## 수정 방법

- **앱 로직·디자인**: `index.html` 하나만 수정하면 됩니다. `<style>` 상단의 CSS 변수(`--accent`, `--save` 등)로 색상을 일괄 변경할 수 있습니다.
- **빠른 할인율 버튼**: `index.html` 스크립트 상단의 `var QUICK = [5,10,15,20,25,30,40,50];` 배열을 수정합니다.
- **파일을 수정한 뒤에는** `sw.js`의 `CACHE_VERSION` 값을 올려야(`discount-calc-v1` → `v2`) 기존 사용자에게 새 버전이 반영됩니다.
